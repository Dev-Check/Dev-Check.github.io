Raspberry Pi Personal Dashboard

Personal Hardware Dashboard

I am planning to develop a Raspberry Pi based personal dashboard that combines hardware, APIs, and software development into a single interactive display.

One idea is creating a Spotify display that shows the currently playing song, album artwork, and additional information using the Spotify API. This project will allow me to explore API integration and embedded development.

Another planned feature is a Dungeons & Dragons companion display that can show my character sheet, health, items, and other information in a physical tabletop setup.

I also want to create a gaming showcase display that can track and display my game collection, achievements, or other gaming-related information.

Apex Inspired Ability System

I am planning to begin learning Java through Minecraft mod development. This project will focus on creating custom abilities inspired by games such as Apex Legends.

The goal is to design unique character abilities, mechanics, and gameplay systems while learning Java, object-oriented programming, and game development concepts.

This project will allow me to combine my interest in gaming with my software development skills while exploring a new programming language.
